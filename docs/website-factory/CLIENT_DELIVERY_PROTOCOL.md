# Two New Clients — Intake and Delivery Protocol
Prepared 2026-10-16. Client names/identities and deadlines remain UNKNOWN; this file does not create client records.

## Immediately usable canonical onboarding
1. Business name and website/social links?
2. Products and services?
3. Location and service area?
4. Ideal customer and primary goal?
5. Preferred visual style and examples?

For each identifiable client, use the existing approved intake location and create one distinct tenant-safe project record after verified identity/consent. Do not copy one client's phone, data or assets into another.

## Delivery

Prioritize real committed client work over framework expansion. No fake testimonials, reviews, staff, business history or rankings.
